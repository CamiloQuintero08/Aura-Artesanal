# Aura Artesanal
Proyecto de semestre basado en un E-commerce para la gestion de ventas de un emprendimiento con productos artesanales ubicado en caldas antioquia.

# Lenguajes de programacion
- Java
- JavaScript
- HTML
- CSS

# Frameworks
- Springboot
- Thymeleaf
- MySQL

# Chatbot
- Dialogflow
